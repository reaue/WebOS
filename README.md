# WebOS

A personal OS based on a space theme, with apps such as Notes and Rock Paper Scissors.

![SpaceOS screenshot](<Capture d'écran 2026-09-08 114547.png>)

# Demo

You can try it **[here](https://reaue.github.io/WebOS/)**.

# Quick start

You can use the link above to access SpaceOS directly in your browser. No installation is required.

# Features

* Top bar with the current date and time, updated every second
* Bottom bar with app icons and app names displayed when you hover over them
* All apps can be dragged, opened, and closed
* Notes are saved in `localStorage`, so your notes remain after closing or refreshing the page
* Functional Rock Paper Scissors game against the computer, with a score

# How to run it locally

Clone the repository and open the project with a local development server.

```bash
git clone https://github.com/reaue/WebOS.git
cd WebOS
```

And then open the project with a local server.

# How it works

WebOS is built with HTML, CSS and JavaScript.

JavaScript handles interactions and features of the OS, such as updating the date and time every second or playing a random move in Rock Paper Scissors.
HTML creates every elements on the website page.
And CSS is used for the style.
