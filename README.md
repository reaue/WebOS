# WebOS

A personal OS based on a space theme, with apps such as Notes and Rock Paper Scissors.

![SpaceOS screenshot](<images/Capture d'écran 2026-09-08 121056.png>)

# Demo

You can try it **[here](https://reaue.github.io/WebOS/)**.

# Quick start

You can use the link above to access SpaceOS directly in your browser (it's a website), no installation is required.

# Features

I implement some features here they are :
- Top bar with the current date and time whoch is updated every second
- Bottom bar where you can select apps with clicking on the icon app and app names are display when you hover over them
- All apps can be dragged, opened, and closed
- Notes are saved in `localStorage`, so your notes remain automatically after closing or refreshing the page
- Functional Rock Paper Scissors game against the computer, with a score which is reset when you reload the page.

# How to run it locally

Clone the repository and open the project with a local development server.

```bash
git clone https://github.com/reaue/WebOS.git
cd WebOS
```

And then open the project with a local server.

# How and why I made this project

I follow the WebOS 1 mission from [stardance](https://stardance.hackclub.com/missions/web-os-1), I only used the explication for main features such as draggable, openable and closeable window. But all the design are my own outlook, I made this project because when I was rating other projects I saw beautiful website OS and I want to do my own. I used a space theme because I like everthing which is connected to the space.
I started with follow the tuto for created my first window and after that I had everything I need to implement my own. So I created an Note app and Rock Paper Scissors app from scratch (with a lot of searchs on google). I'm pretty happy with the render of translucent windows.
This project also help me to undestand more how web devlopment works.
